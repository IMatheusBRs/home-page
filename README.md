# Matheus Sousa — página pessoal

Portfólio profissional em React e Vite para `matheussousa.orzyon.ai`.

A página apresenta Matheus como Engenheiro Sênior de Plataforma de IA e SRE, com foco em infraestrutura de IA, automação, MLOps, LLMOps, observabilidade e segurança. O conteúdo foi estruturado a partir do currículo profissional fornecido para o projeto.

## Desenvolvimento

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

O resultado estático é gerado em `dist/`.

## Estrutura principal

- `src/App.jsx` — conteúdo e componentes da página.
- `src/styles.css` — direção visual e comportamento responsivo.
- `public/og.png` — imagem de compartilhamento social.
- `deploy/` — estrutura de publicação preservada para a etapa de deploy.
